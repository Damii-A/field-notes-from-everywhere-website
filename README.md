# Field Notes From Everywhere

Book-recommendation editorial website: a free Publication (three editorial columns) and The
Reading Room, a paid daily-newsletter product.

No application code exists yet — this repository currently holds project setup and
engineering documentation from initialization. Start here:

- **`CLAUDE.md`** — entry point for AI coding sessions: governing sources, working rules,
  escalation rules.
- **`ARCHITECTURE.md`** — the proposed production architecture (Next.js + Sanity + Kit +
  Paddle on Vercel) and why.
- **`DECISIONS.md`** — consequential engineering decisions and their reasoning.
- **`CURRENT_STATE.md`** — what's built, what's next, what's blocked on external accounts.
- **`docs/design-specs/`** — the original product/experience specifications, mirrored from
  the Claude Design project that defines this product.
